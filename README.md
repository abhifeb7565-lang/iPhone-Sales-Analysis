# iPhone-Sales-Analysis
iPhone Sales Analysis is a data analytics project that explores Apple iPhone sales data from Flipkart using Python. The project focuses on performing Exploratory Data Analysis (EDA) to uncover insights related to product ratings, customer reviews, pricing patterns, discounts, and popular iPhone models.

Using libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Plotly, the dataset was cleaned, processed, and visualized to identify trends and relationships within the data. Various charts and interactive visualizations were created to analyze customer preferences, highly rated products, review distributions, and price variations across different iPhone models and storage configurations.

Key objectives of the project include:

Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Customer rating and review analysis
Price and discount trend analysis
Data visualization and storytelling
Generating actionable business insights
